# フリーランス・副業向け 小さな実用ツール集

外部API・サーバー不要の静的HTMLツール。GitHub Pages 等にそのまま置けば動きます。

## 0. ツール一覧（ハブ）（`tools.html`）
- 各ツールへのカード一覧と、差し替え用の「関連情報・おすすめ」案内エリア（プレースホルダー）
- **ツールの追加方法**：`tools.html` の `<ul class="tool-list">` 内の `<li>` を1つコピーして書き換え、新ツールのページ上部に `<a class="back" href="./tools.html">← ツール一覧へ</a>` を入れる
- 各ツールの上部「← ツール一覧へ」からここに戻れます

## 1. 源泉徴収・請求額 逆算電卓（`index.html`）
- **報酬 → 手取り**：税抜報酬額から消費税・源泉徴収税（10.21%／100万円超の部分は20.42%）・振込手数料を差し引いた振込額を計算
- **手取り → 報酬**：口座に入ってほしい金額から、必要な税抜報酬額を逆算
- 源泉の対象（税抜／税込）、消費税の端数処理、振込手数料を設定可能。内訳コピー、端末内履歴

## 2. 確定申告 準備・抜け漏れチェッカー（`checklist.html`）
- 働き方・源泉徴収・インボイス・経費メモ・控除・提出方法をタップで選ぶと、準備項目を5カテゴリに整理して表示
- 各項目をタップで「確認済み／未確認」切替、進捗（件数・％）表示、未確認だけ表示、未確認リストのコピー
- 状況とチェックは端末内（localStorage）にのみ保存
- 税額計算や申告要否・控除可否の判断は行わない「準備の目安」ツール
- ページ下部の「関連情報・おすすめ」は差し替え用プレースホルダー（`<a class="slot">` の href・文言を置き換え。アフィリエイトは `rel="sponsored noopener"` と PR 表記を付ける）
