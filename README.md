# 源泉徴収・請求額 逆算電卓

フリーランス・個人事業主向けの単機能Webツール（`index.html` 1ファイル、外部API・サーバー不要）。

- **報酬 → 手取り**：税抜報酬額から消費税・源泉徴収税（10.21%／100万円超の部分は20.42%）・振込手数料を差し引いた振込額を計算
- **手取り → 報酬**：口座に入ってほしい金額から、必要な税抜報酬額を逆算
- 源泉の対象（税抜／税込）、消費税の端数処理、振込手数料（こちら負担）を設定可能
- 請求書・メール用の内訳テキストをコピー、計算履歴を端末内（localStorage）に保存

GitHub Pages 等の静的ホスティングにそのまま置けば動きます。
