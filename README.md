# 請求・確定申告のかんたんツール（フリーランス・副業・経理初心者向け）

外部API・サーバー不要の静的HTMLツール。GitHub Pages 等にそのまま置けば動きます。

## 0. ツール一覧（ハブ）（`tools.html`）
- 各ツールへのカード一覧と、差し替え用の「関連情報・おすすめ」案内エリア（プレースホルダー）
- ツールは「請求・報酬まわり」「確定申告まわり」のグループ別に表示
- **ツールの追加方法**：該当グループの `<ul class="tool-list">` 内の `<li>` を1つコピーして書き換え（新グループは `<section class="tool-group">` ごとコピー）、新ツールのページ上部に `<div class="topbar"><a class="back" href="./tools.html">← ツール一覧へ</a></div>` を入れる
- 各ツールの上部「← ツール一覧へ」からここに戻れます

## 1. 源泉徴収・請求額 逆算電卓（`index.html`）
- **報酬 → 手取り**：税抜報酬額から消費税・源泉徴収税（10.21%／100万円超の部分は20.42%）・振込手数料を差し引いた振込額を計算
- **手取り → 報酬**：口座に入ってほしい金額から、必要な税抜報酬額を逆算
- 源泉の対象（税抜／税込）、消費税の端数処理、振込手数料を設定可能。内訳コピー、端末内履歴

## 2. 確定申告 準備・抜け漏れチェッカー（`checklist.html`）
- 働き方・源泉徴収・インボイス・経費メモ・控除・提出方法をタップで選ぶと、準備項目を5カテゴリに整理して表示
- 各項目をタップで「確認済み／未確認」切替、進捗（件数・％）表示、未確認だけ表示、未確認リストのコピー
- 状況とチェックは端末内（localStorage）にのみ保存
- 税額計算や申告要否・控除可否の判断は行わない「準備の目安」ツール
- ページ下部の「関連情報・おすすめ」は差し替え用プレースホルダー（`<a class="slot">` の href・文言を置き換え。アフィリエイトは `rel="sponsored noopener"` と PR 表記を付ける）

## 3. 請求書 記載漏れチェッカー（`invoice-check.html`）
- 書類の種類（請求書／報酬・金額の連絡／見積もり）・インボイス登録・源泉徴収の有無に合わせて、宛先・金額内訳・消費税／源泉徴収・支払条件／振込先・送付前確認の項目を表示
- タップで確認済み切替、進捗表示、未確認のコピー、取引先メモ、「次の書類へ」で毎回リセットして使える
- 記載要件や税務・契約上の判断は行わない見直し用リスト。データは端末内（localStorage）のみ

## 4. 年間収入・経費 振り返りメモ（`income-memo.html`）
- 月ごとの報酬・源泉徴収された額・経費の目安を入力し、年間合計・差引・報酬−経費・平均・最多月と月別の棒グラフを表示
- バックアップの書き出し（JSONファイル／テキストコピー）と読み込み（ファイル／貼り付け）、最終バックアップ日の表示
- 年ごとに記録（1〜3月は前年を初期表示）、報酬の記録方法（税抜／税込）、年間まとめのコピー
- 税額の確定や申告要否の判断は行わない目安メモ。データは端末内（localStorage）のみ

## サイト共通の仕組み
- 公開：Cloudflare Workers（`https://test-app.kaikeilab.workers.dev`）。`main` へのプッシュで自動デプロイ
  - `wrangler.jsonc`：Cloudflareが自動生成していた設定と同じ内容に、`not_found_handling: "404-page"`（存在しないURLで `404.html` を返す）を追加
  - `.assetsignore`：`wrangler.jsonc`・`README.md` を公開しない
- URLは拡張子なしが正式（例：`/tools`）。`.html` 付きは自動で転送される。サイト内リンクも拡張子なしに統一
- SEO：各ページに canonical・OGP（`og-image.png`）・アイコン（`favicon.ico` / `favicon.svg` / `apple-touch-icon.png`）。`sitemap.xml`・`robots.txt`
- `about.html`：運営者情報・免責事項・プライバシーポリシー・お問い合わせ・国税庁リンク
- `site.css`：使い方・FAQ、有料商品の案内枠、フッターリンクの共通スタイル
- **`site.js`：販売ページのURL（`PRODUCTS`）とお問い合わせフォームのURL（`SITE.contactUrl`）はここだけ書き換えれば全ページに反映**（空欄のあいだは「準備中」表示）
- ページを追加したら `sitemap.xml` にも追記する
